# Metrokey
JA:
'紹介
Windows CEで使えるシンプルなMetro UI風のソフトウェアキーボードです。
Dockモードで下部にキーボードを固定、
Floatモードでキーボードを自由に動かしたりサイズ変更できます。
Dockモードを使ってキーボードサイズを変えるととウィンドウのサイズ、作業領域も同時に変わります
'動作環境
Windows Pocket PC 2003 SEエミュレータ, SHARP Brain PW-SH4実機で動作しました。
多分ほとんどのデバイスで動くとは思いますが、Armじゃないと動作しないので注意
もしArm以外で動かす場合はソースコードを自分でコンパイルしてください。
'注意

# Metrokey
JA:
'Introduction
A simple, Metro UI-style software keyboard for Windows CE.
In "Dock" mode, the keyboard is fixed to the bottom of the screen.
In "Float" mode, the keyboard can be moved freely and resized.
When using "Dock" mode, resizing the keyboard also adjusts the window size and the available workspace.
'System Requirements
Tested and confirmed to work on a Windows Pocket PC 2003 SE emulator and a SHARP Brain PW-SH4 device.
It should work on most devices, but please note that it requires an ARM-based processor.
If you wish to run it on a non-ARM architecture, please compile the source code yourself.
